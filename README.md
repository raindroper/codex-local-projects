# Codex 本机项目补齐工具

在同一台 Windows 电脑上切换 Codex 账号后，从本机保存的历史账号记录中，补齐当前账号缺少的本地项目入口和对话分组。

这是非官方辅助工具。每台电脑使用自己的记录，可以把同一套工具复制到多台电脑使用。它按需补齐数据，不提供跨电脑同步或实时双向同步。

## 下载与使用

从 [Releases](https://github.com/raindroper/codex-local-projects/releases/latest) 下载 `CodexLocalProjects-Windows.zip`，解压整个文件夹。

1. 在 Codex 中登录**切换后的账号**，也就是接下来要使用的账号。例如从 A 切换到 B，就保持 **B** 登录。
2. 保持 Codex 打开，双击工具文件夹里的 **`Sync.cmd`**。
3. 没有缺项时，只检查。有缺项时，会显示数量、倒数 8 秒，然后关闭 Codex，备份并补齐记录，再自动打开应用并校验。

**如果刚打开 Codex、尚未发起任何任务，直接运行即可。** 只有对话正在生成回复、写代码或执行命令时，才需要先等它结束。历史对话不属于“正在执行的任务”。

倒数期间可按 `Ctrl+C` 取消。恢复期间等待工具自动重开应用，保持当前账号即可。

已经补齐的账号通常不用每次处理。首次使用其他账号，或在其他账号新增了项目、对话分组后，可以再次运行。当前电脑必须仍保存着可导入的历史记录。

## 适用范围

- Windows 安装包版 Codex；自动识别用户目录、安装位置和当前账号。
- 默认使用 `%USERPROFILE%\.codex`，也支持 `CODEX_HOME` 环境变量。
- 优先使用 Codex 内置 Node.js；找不到内置运行时才使用系统的 Node.js 20+。
- 无 npm 运行依赖，无联网、上传、开机启动项或常驻服务。
- 已在 `OpenAI.Codex 26.1103.3517.0` 上适配和检查。后续版本改变内部数据格式时，工具可能需要更新。

只补齐缺失的本地项目和分组，当前账号已有的命名、归属和设置优先。云端关联项目、远程主机记录以及有冲突的历史分组会跳过。不读取 `auth.json`，不修改项目代码、登录凭据或其他账号的保存状态。

删除、改名和移动分组不会自动同步。其他账号还保留的项目可能再次被补入，因此请把它作为缺项恢复工具使用。

## 仅检查与自定义目录

在工具目录打开 PowerShell，运行：

```powershell
.\Sync-CodexProjects.ps1 -CheckOnly
```

自定义 Codex 数据目录：

```powershell
.\Sync-CodexProjects.ps1 -CodexHome 'D:\CodexData' -CheckOnly
```

也可以在命令提示符中运行 `Sync.cmd -CheckOnly`。仅检查模式不会关闭应用或写入应用状态。

## 备份与报告

每次实际修改前，会把当时的完整状态文件保存到：

```text
%LOCALAPPDATA%\CodexLocalProjects\runs\<本次运行目录>\
```

- `state.before.json`：修改前的备份。
- `plan.json`：本次补齐计划。
- `result.json`：写入结果。

这些运行文件可能包含本地路径、对话标题或界面状态，留在本机即可。仓库和发行包仅包含程序、说明及虚构测试数据。

## 开发与测试

需要 Node.js 20+，无需安装依赖：

```shell
npm test
npm run check
```

测试使用临时目录和虚构账号，覆盖缺项补齐、重复运行、已有设置保留、分组冲突、云端关联记录排除、账号切换保护，以及命令行备份、写入和验证流程。测试不会读取或修改使用者的 Codex 数据。
