Codex 本机项目补齐工具 — Windows 通用版

用途
每台电脑使用自己的 Codex 本地记录。换账号后，把这台电脑上其他账号保存的本地项目入口和对话分组，补齐到当前登录账号。
这是非官方辅助工具，并不是关闭账号隔离的官方配置，也不是实时双向同步。

使用方法
1. 把整个 CodexLocalProjects 文件夹复制到需要处理的 Windows 电脑，并先解压。
2. 打开 Codex，登录切换后的账号。例如从 A 换到 B，就保持 B 登录并让 Codex 开着，无需切回 A。
3. 双击 Sync.cmd。刚打开且没有发起任务时，直接运行即可；只有对话正在生成回复、写代码或执行命令时，才需要先等它完成。历史对话不算正在执行的任务。
4. 已经齐全：只检查，不重启、不修改应用配置。
   有缺项：显示待补齐数量，倒数 8 秒后关闭 Codex，备份并补齐数据，再重新打开并校验。
   倒数期间可按 Ctrl+C 取消。执行时不要同时换账号或手动重开 Codex。

日常使用
已补齐的账号再次登录，通常不需要重复处理。
首次使用另一个账号，或在其他账号新增了项目/对话分组后，再运行一次。
每台电脑独立运行，程序只读取本机记录，不会从另一台电脑下载项目、代码或对话。
如果这台电脑从来没有保存过原项目记录，工具无法凭空找回；需要先打开原项目文件夹或恢复这台电脑自己的备份。

边界
• 自动识别当前 Windows 用户、Codex 安装位置、当前登录账号和本机的历史账号记录。
• 默认数据目录为当前用户的 .codex；支持 CODEX_HOME 环境变量。
• 使用 Codex 内置 Node.js；内置运行时不存在时，才尝试本机 Node.js 20+。
• 只添加缺失的本地项目入口和分组，保留当前账号已有的命名、归属与设置。
• 不读取 auth.json，不修改登录凭据、云端项目、其他账号状态或项目代码。
• 不迁移关联 ChatGPT 云端项目的记录，不合并远程主机项目。
• 同一条对话在多个历史账号中有不同归属时，不替你选择，报告冲突并跳过。
• 不同步删除：其他账号还保留的项目可能被重新添加。不要把它当作完全镜像同步工具。
• 本地状态格式不兼容、当前账号在处理过程中变化或检测到并发写入时，会停止处理。

备份
每次实际修改前，完整保存当时的状态文件。
备份和报告位于本机 %LOCALAPPDATA%\CodexLocalProjects\runs 下的独立时间目录。
state.before.json 是修改前备份；plan.json 是计划；result.json 是执行结果。
备份可能含本地对话标题及界面状态，请留在自己的电脑上。

仅检查
在 PowerShell 中运行：
  .\Sync-CodexProjects.ps1 -CheckOnly
使用自定义目录：
  .\Sync-CodexProjects.ps1 -CodexHome 'D:\CodexData' -CheckOnly

适用范围与验证
启动器支持 Windows 安装包版 Codex，可复制到不同 Windows 电脑使用。
本次适配版本为 OpenAI.Codex 26.1103.3517.0。未来版本可能更改内部状态格式，不能保证永久兼容。
已验证：新账号补齐、重复运行无改动、当前账号设置优先、冲突分组跳过、云端关联记录排除、账号切换中断保护，以及实际 Windows 启动器的仅检查流程。
核心只处理 JSON 元数据；未修改应用程序安装包，也未安装常驻服务、计划任务或开机启动项。
其他操作系统需要相应的应用关闭/重开适配，不能直接运行这个 Windows 启动器。
